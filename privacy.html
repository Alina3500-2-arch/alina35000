Политика конфиденциальности

Настоящая политика конфиденциальности описывает, как обрабатываются данные пользователей при взаимодействии с Instagram-аккаунтом и автоматической выдачей ссылки на бесплатный шаблон.

1. Какие данные могут обрабатываться

При использовании автоматической воронки могут обрабатываться технические данные из Instagram: текст комментария, идентификатор комментария, имя пользователя Instagram, идентификатор публикации, а также факт взаимодействия с публикацией.

2. Для чего используются данные

Данные используются только для того, чтобы определить, оставил ли пользователь комментарий с ключевым словом, и отправить ему ответное сообщение со ссылкой на бесплатный материал.

3. Передача данных третьим лицам

Данные не продаются, не передаются рекламным сетям и не используются для сторонней рассылки. Техническая обработка может происходить через сервисы Meta, Cloudflare и GitHub Pages, которые используются для работы страницы и автоматического ответа.

4. Хранение данных

Система может временно сохранять идентификатор обработанного комментария, чтобы не отправлять повторные ответы на один и тот же комментарий.

5. Удаление данных

Пользователь может запросить удаление связанных с ним данных, написав на email: YOUR_EMAIL@example.com.

6. Контакты

По вопросам обработки данных можно написать на email: YOUR_EMAIL@example.com.
