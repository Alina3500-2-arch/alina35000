# Монтажная

Здесь всё, что нужно, чтобы ты кидала идеи и исходники, а на выходе получала готовый вертикальный ролик.

## Как это работает

1. **Ты кидаешь идею** — текстом: «ролик 20 секунд про утро, три сцены, в конце призыв подписаться».
2. **Ты кидаешь исходники** — видео/фото/музыку. Варианты:
   - загрузить в Google Drive (я подключена к твоему Диску и скачаю сама);
   - приложить файлы прямо в чат;
   - если исходников нет — соберу ролик из титров, фона и твоих фото.
3. **Я пишу план монтажа** (`plan.json`) и рендерю его в mp4 через ffmpeg.
4. **Правки** — говоришь «вторую сцену короче, текст выше», я меняю план и пере-рендерю.

Редактор в браузере (`editor.html`) нужен, если хочешь порезать сама: там таймлайн, подрезка, подписи, музыка и превью. На выходе он даёт тот же `plan.json` — копируешь и присылаешь мне.

## Установка (один раз в новой сессии)

```bash
bash video/setup.sh          # ставит ffmpeg (статическая сборка, без root-пакетов)
```

## Рендер

```bash
python3 video/render.py plan.json           # собрать видео
python3 video/render.py plan.json --dry-run # показать команду ffmpeg, ничего не рендерить
```

Пути внутри плана считаются относительно папки с самим `plan.json`.

## Формат из рефа (говорящая голова + подписи)

Ролик, который ты показала, разбирается на четыре слоя:

| Слой | Что это | Как задать |
|---|---|---|
| Склейки | куски без пауз, спикер говорит без «эээ» | `python3 video/speech.py talk.mp4 --cut` |
| Реплики | крупный капс по центру-низу, меняется по фразам | подписи со `"style": "sub"` |
| Шапка | «РУБРИКА \| ТЕМА» вверху, весь ролик, полупрозрачная | `"style": "header"` |
| Бренд | название внизу, весь ролик, с разрядкой | `"style": "brand"` |

Пример такого плана — `plan.reels.json`.

### Подписи из речи

```bash
# где человек говорит, где паузы
python3 video/speech.py raw/talk.mp4

# нарезка без пауз -> вставить в clips
python3 video/speech.py raw/talk.mp4 --cut > clips.json

# подписи: текст из сценария, тайминги из пауз
python3 video/speech.py raw/talk.mp4 --script scenario.txt > texts.json

# подписи полностью автоматом (нужен доступ к huggingface.co)
python3 video/speech.py raw/talk.mp4 --whisper > texts.json
```

Сценарий — обычный txt, по фразе на строку; фразы раскладываются по речевому времени, длинным достаётся больше.

**Про `--whisper`:** распознавание речи ставится из pypi (`faster-whisper`), но веса модели тянутся с `huggingface.co`, а он закрыт сетевой политикой окружения. Чтобы включить автосубтитры, добавь `huggingface.co` в разрешённые домены окружения (claude.ai/code → Environments → network policy). До этого работает `--script`.

## Стили подписей

`"style"` выбирает готовый набор: положение, кегль, капс, прозрачность, плашку. Любое поле подписи перекрывает стиль.

| Стиль | Вид |
|---|---|
| `sub` | реплика: крупный капс, центр-низ, без плашки, тонкая обводка |
| `header` | шапка ролика: мелкий капс с разрядкой, вверху, 60% прозрачности |
| `brand` | подпись бренда внизу, капс с широкой разрядкой |
| `title` | крупный титр с плашкой — для хука и призыва в конце |

## Формат плана

| Поле | Что делает |
|---|---|
| `output` | имя итогового файла, по умолчанию `out.mp4` |
| `width` / `height` / `fps` | холст, по умолчанию 1080×1920 @ 30 (Reels, TikTok, Shorts) |
| `crf` | качество, 18 — очень хорошо, 20 по умолчанию, 26 — легче файл |
| `keep_audio` | брать ли звук из исходных клипов (по умолчанию да) |

**Клип** (`clips`, по порядку):

| Поле | Что делает |
|---|---|
| `src` | файл: видео, jpg/png/webp |
| `start` / `end` | подрезка видео в секундах |
| `duration` | длительность для фото |
| `speed` | 1.5 — ускорить, 0.5 — замедлить (звук подтягивается) |
| `zoom` | для фото: `in` — наезд, `out` — отъезд |
| `fade` | затемнение в начале и в конце клипа, в секундах |
| `mute` / `volume` | убрать или приглушить звук клипа |
| `crop` | `[x, y, ширина, высота]` в долях — обрезать кадр, например срезать интерфейс приложения с экранной записи |

Кадр всегда заполняется целиком (обрезка по центру), так что горизонтальные исходники в вертикали не дадут чёрных полос.

**Подпись** (`texts`, поверх всего ролика):

| Поле | Что делает |
|---|---|
| `text` | текст, `\n` — перенос строки |
| `start` / `end` | когда показывать, в секундах от начала ролика |
| `y` | высота: `0` — верх, `1` — низ, `0.78` — типичное место субтитра |
| `style` | `sub`, `header`, `brand` или `title` — см. выше |
| `size` | кегль в пикселях холста |
| `opacity` | прозрачность текста, `0.6` — полупрозрачная шапка |
| `spacing` | разрядка между буквами |
| `uppercase` | перевести в капс |
| `color` | `#ffffff` или имя: white, yellow, pink, red, blue, green, orange |
| `box` / `box_opacity` | плашка под текстом (по умолчанию есть, 55% чёрного) |

**Музыка** (`music`): `src`, `volume` (0.22 — фон под голос), `fade_out`.

Пример целиком — `plan.example.json`.
